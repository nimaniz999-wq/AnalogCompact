آنالوگ کمپانی — نسخهٔ ۵

تغییرات
- آنالوگ رکوردز کاملاً با نسخهٔ جدیدش جایگزین شد (apps/rec.html و پوشهٔ assets).
- گرامافون و دیسک‌ها حالا در همهٔ پنجره‌ها هستند: دکمهٔ گرد دیسکی پایین صفحه (قابل کشیدن) را بزن تا گرامافون باز شود.
  موسیقی هنگام رفتن به صفحهٔ اصلی و بین اپ‌های روزانه، قاب، چراغ مطالعه و پاپ‌کورن قطع نمی‌شود.
- دیسک‌ها با خود آنالوگ رکوردز مشترک‌اند: هر دیسکی آنجا یا اینجا بسازی، در هر دو دیده می‌شود.
- داخل خود آنالوگ رکوردز، گرامافون همان‌جاست و دکمهٔ گرد مخفی می‌شود (موسیقی آن‌جا جداست).

آپلود روی GitHub Pages (رایگان)
۱) در github.com یک repository Public بساز.
۲) همهٔ فایل‌ها و پوشه‌ها (شامل .github) را آپلود کن.
۳) در Settings > Pages، Source را روی GitHub Actions بگذار و بعد از چند دقیقه آدرس را باز کن.

نصب: Chrome/Edge > Install (ویندوز) یا Install app (اندروید).
بعد از آپلود نسخهٔ جدید، یک بار برنامه را کامل ببند و دوباره باز کن تا کش قدیمی عوض شود.
